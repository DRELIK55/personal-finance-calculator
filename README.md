# Калькулятор личных финансов

Консольное приложение на Python для учета доходов и расходов.

Возможности
- Добавление операции (доход/расход) с суммой, категорией и датой.
- Просмотр списка всех операций.
- Вывод текущего баланса.

Установка и запуск
Для работы требуется Python 3.x.
1. Склонируйте репозиторий:
   `git clone https://github.com/DRELIK55/personal-finance-calculator.git`
2. Перейдите в папку проекта:
   `cd personal-finance-calculator`
3. Запустите приложение:
   `python src/main.py`
